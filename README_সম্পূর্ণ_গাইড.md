# IS Fashion — পুশ নোটিফিকেশন + OTP সম্পূর্ণ সেটআপ গাইড (১০০% ফ্রি)

## ০. সংক্ষেপে: কী কী লাগবে

| কী | কয়টি | কাজ |
|---|---|---|
| **Firebase প্রজেক্ট** | **১টি** | ডাটাবেস (Firestore) + পুশ (FCM) — সব এক প্রজেক্টেই |
| **Render সার্ভার** | **১টি** | এই এক সার্ভারেই পুশ নোটিফিকেশন **এবং** OTP — দুই কাজ |
| **জিমেইল অ্যাকাউন্ট** | ১টি | OTP এই জিমেইল থেকে যাবে (আপনি নিজে খুলবেন) |
| **GitHub অ্যাকাউন্ট** | ১টি | Render এর জন্য সার্ভারের কোড রাখতে |
| **ওয়েব হোস্টিং** | ২টি সাইট | একটি ইউজার সাইট, একটি অ্যাডমিন সাইট (Netlify ফ্রি) |

> পুরনো `Push Notifications Sender.html` ও আলাদা পুশ-ফাইল/আলাদা Firebase আর লাগবে না। সব এডমিন প্যানেল থেকেই চলবে।

### ফোল্ডারে কী আছে
```
IS_Fashion_Complete/
├─ 1-user-site/        ← ইউজার সাইট (index.html + firebase-messaging-sw.js)
├─ 2-admin-site/       ← অ্যাডমিন প্যানেল (index.html)
├─ 3-server/           ← Render সার্ভার (পুশ + OTP)
├─ firestore.rules     ← Firestore এর সিকিউরিটি রুলস
└─ README_সম্পূর্ণ_গাইড.md  ← এই ফাইল
```

### পুরো সিস্টেম কীভাবে চলে
1. অ্যাডমিন প্যানেলে নোটিফিকেশন লিখলে ডাটাবেসে সেভ হয় → অ্যাডমিন প্যানেল সার্ভারকে জানায় → সার্ভার সবার (বা নির্দিষ্ট ইউজারের) ফোনে পুশ পাঠায়।
2. অর্ডার/পেমেন্ট/বার্তার উত্তরের মতো **সিস্টেমের নিজে থেকে আসা** নোটিফিকেশনও একই পথে পুশ হয়ে যায়।
3. ইউজার "পাসওয়ার্ড ভুলে গেছি" চাপলে সার্ভার ৪ সংখ্যার কোড বানিয়ে জিমেইলে পাঠায় (ও পুশেও)। সঠিক কোড দিলে নতুন পাসওয়ার্ড সেট হয়।

## ধাপ ১ — Firebase বানানো (শুরু থেকে)

### ১.১ প্রজেক্ট তৈরি
1. https://console.firebase.google.com খুলুন → আপনার জিমেইল দিয়ে লগইন।
2. **Create a project** (বা Add project) → নাম দিন, যেমন `is-fashion` → Continue।
3. Google Analytics **বন্ধ** রাখুন (দরকার নেই) → **Create project** → Continue।

### ১.২ Firestore ডাটাবেস
1. বাঁ মেনু **Build → Firestore Database → Create database**।
2. Location: `asia-south1 (Mumbai)` বা `asia-southeast1 (Singapore)` (বাংলাদেশের কাছের) — পরে বদলানো যায় না।
3. **Start in production mode** → Create।
4. উপরের **Rules** ট্যাবে যান → সব মুছে এই প্যাকেজের `firestore.rules` ফাইলের লেখা পেস্ট করুন → **Publish**।

### ১.৩ ওয়েব অ্যাপ যোগ করে কনফিগ নেওয়া
1. ⚙️ **Project settings** (বাঁ উপরে গিয়ার) → General → নিচে **Your apps** → `</>` (Web) আইকন।
2. App nickname: `is-fashion-web` → **Register app** (Hosting টিক দেবেন না)।
3. একটি `firebaseConfig = { apiKey: "...", authDomain: "...", ... }` দেখাবে — **এটি কপি করে রাখুন**।

### ১.৪ VAPID Key (ওয়েব পুশের চাবি)
1. Project settings → **Cloud Messaging** ট্যাব।
2. নিচে **Web configuration → Web Push certificates → Generate key pair**।
3. যে লম্বা কী (`B...` দিয়ে শুরু) আসবে সেটি কপি করে রাখুন। এটি পরে অ্যাডমিন প্যানেলের সেটিংসে বসবে।
4. ওই পেজেই দেখুন **Firebase Cloud Messaging API (V1)** "Enabled" আছে কিনা। না থাকলে তার তিন-ডট মেনু → **Manage API in Google Cloud Console** → **Enable**।

### ১.৫ সার্ভারের চাবি (Service Account)
1. Project settings → **Service accounts** ট্যাব → **Generate new private key** → Generate key।
2. একটি `.json` ফাইল নামবে। **এটি সবচেয়ে গোপন জিনিস** — কাউকে দেবেন না, GitHub এ তুলবেন না। ধাপ ৩ এ Render এ বসাব।

## ধাপ ২ — জিমেইল দিয়ে OTP পাঠানোর ব্যবস্থা (Gmail API)

> **কেন সাধারণ SMTP/অ্যাপ-পাসওয়ার্ড নয়?** Render এর ফ্রি সার্ভারে SMTP পোর্ট (25/465/587) বন্ধ, তাই চলে না। Gmail API সাধারণ ইন্টারনেট পোর্টে চলে, ফ্রি, আর মেইল সরাসরি **আপনার নিজের জিমেইল থেকে** যায় বলে ইনবক্সে পৌঁছানোর সম্ভাবনা সবচেয়ে বেশি।

আগে একটি জিমেইল ঠিক করুন যেটি থেকে OTP যাবে (যেমন `isfashion.otp@gmail.com`)। এটি আপনি নিজেই খুলে দেখতে পারবেন। **এই জিমেইলে ২-ধাপ যাচাই (2-Step Verification) চালু রাখা ভালো।**

### ২.১ Gmail API চালু
1. https://console.cloud.google.com → উপরে প্রজেক্ট বাছাইয়ে **ধাপ ১ এ বানানো `is-fashion` প্রজেক্টটিই** নিন (Firebase আর এটি একই প্রজেক্ট)।
2. **APIs & Services → Library** → "Gmail API" খুঁজুন → **Enable**।

### ২.২ OAuth Consent Screen
1. **APIs & Services → OAuth consent screen** (নতুন ভার্সনে *Google Auth Platform*)।
2. User type: **External** → Create/Get started।
3. App name: `IS Fashion`, User support email ও Developer email: আপনার জিমেইল → Save।
4. **Data access / Scopes** → Add scope → `https://www.googleapis.com/auth/gmail.send` যোগ করুন → Save।
5. **Audience / Test users** → **Add users** → যে জিমেইল থেকে OTP পাঠাবেন সেটি যোগ করুন।
6. ⚠️ **অত্যন্ত জরুরি:** Audience পেজে **Publish app** চাপুন (Status: *In production*)। না করলে "Testing" অবস্থায় রিফ্রেশ টোকেন **৭ দিন পর মরে যায়** এবং OTP হঠাৎ বন্ধ হয়ে যাবে। (ভেরিফিকেশন চাইলে দরকার নেই — শুধু নিজের অ্যাকাউন্টে ব্যবহার করছেন।)

### ২.৩ OAuth Client ID
1. **APIs & Services → Credentials → Create credentials → OAuth client ID**।
2. Application type: **Web application**, নাম `is-fashion-otp`।
3. **Authorized redirect URIs → Add URI:** `https://developers.google.com/oauthplayground`
4. Create → **Client ID** ও **Client secret** কপি করে রাখুন।

### ২.৪ Refresh Token নেওয়া
1. https://developers.google.com/oauthplayground খুলুন।
2. ডানের উপরে ⚙️ গিয়ার → **Use your own OAuth credentials** টিক → ২.৩ এর Client ID ও Client secret বসান → Close।
3. বাঁয়ে নিচে "Input your own scopes" ঘরে লিখুন: `https://www.googleapis.com/auth/gmail.send` → **Authorize APIs**।
4. **OTP পাঠানোর জিমেইল** দিয়ে লগইন করুন। "Google hasn't verified this app" দেখালে **Advanced → Go to IS Fashion (unsafe)** → Continue → অনুমতি দিন।
5. **Exchange authorization code for tokens** চাপুন → **Refresh token** (`1//0...`) কপি করে রাখুন।

এখন আপনার কাছে ৪টি জিনিস: `GMAIL_USER` (জিমেইল ঠিকানা), `GMAIL_CLIENT_ID`, `GMAIL_CLIENT_SECRET`, `GMAIL_REFRESH_TOKEN`।

## ধাপ ৩ — সার্ভার Render এ হোস্ট করা

### ৩.১ GitHub এ কোড তোলা
1. https://github.com এ অ্যাকাউন্ট খুলুন → **New repository** → নাম `is-fashion-server` → **Private** → Create।
2. **uploading an existing file** চাপুন → `3-server` ফোল্ডারের **ভেতরের** সব (`src` ফোল্ডার, `package.json`, `render.yaml`, `.gitignore`) টেনে ছেড়ে দিন → Commit।
3. ❌ ভুলেও Service Account এর `.json` ফাইল তুলবেন না।

### ৩.২ Render এ সার্ভার বানানো
1. https://render.com → GitHub দিয়ে সাইন আপ।
2. **New + → Web Service** → আপনার `is-fashion-server` রিপো বাছুন → Connect।
3. সেটিংস: Language **Node** · Build Command `npm install` · Start Command `npm start` · Instance Type **Free**।
4. **Environment Variables** এ যোগ করুন (Add Environment Variable):

| Key | Value |
|---|---|
| `ADMIN_KEY` | নিজে বানানো লম্বা এলোমেলো চাবি (২০+ অক্ষর, যেমন `Kx9fT2mQwL7vBn4RzP8sYd3H`)। লিখে রাখুন |
| `GMAIL_USER` | OTP পাঠানোর জিমেইল ঠিকানা |
| `GMAIL_CLIENT_ID` | ধাপ ২.৩ থেকে |
| `GMAIL_CLIENT_SECRET` | ধাপ ২.৩ থেকে |
| `GMAIL_REFRESH_TOKEN` | ধাপ ২.৪ থেকে |
| `STORE_NAME` | `IS Fashion` |

5. **Secret File:** Environment পেজেই নিচে **Secret Files → Add Secret File** → Filename: `serviceAccountKey.json` → Contents: ধাপ ১.৫ এর `.json` ফাইলটি নোটপ্যাডে খুলে **পুরোটা** কপি-পেস্ট।
6. **Create Web Service** → কয়েক মিনিটে "Live" হবে। উপরে একটি ঠিকানা দেখাবে, যেমন `https://is-fashion-server.onrender.com` — **এটি কপি করে রাখুন**।
7. ব্রাউজারে `https://আপনার-ঠিকানা/health` খুললে `{"ok":true,...}` দেখালে সার্ভার ঠিক।
8. Logs এ সবুজ লেখা দেখবেন: `✅ IS Fashion সার্ভার চালু ... Gmail: সেট ... ADMIN_KEY: সেট`।

### ৩.৩ সার্ভার ঘুমিয়ে পড়া ঠেকানো (খুব দরকারি)
Render ফ্রি সার্ভার ১৫ মিনিট ব্যবহার না হলে ঘুমায়; পরের রিকোয়েস্টে জাগতে ৩০–৬০ সেকেন্ড লাগে। এতে OTP/পুশ দেরি হয়। সমাধান (ফ্রি):
1. https://uptimerobot.com → ফ্রি অ্যাকাউন্ট → **Add New Monitor**।
2. Type: HTTP(s) · URL: `https://আপনার-ঠিকানা/health` · Interval: **5 minutes** → Create।
এতে সার্ভার সবসময় জাগা থাকবে (ফ্রি ৭৫০ ঘণ্টা/মাসে একটি সার্ভার সারা মাস চলে)।

## ধাপ ৫ — ইউজার ও অ্যাডমিন সাইট অনলাইনে তোলা

পুশের জন্য সাইট অবশ্যই **https** হতে হবে। সবচেয়ে সহজ ফ্রি উপায় Netlify:
1. https://app.netlify.com/drop খুলুন → সাইন আপ করুন (না করলে সাইট কিছুক্ষণ পর মুছে যায়)।
2. **`1-user-site` ফোল্ডারটি** টেনে ছেড়ে দিন → একটি ঠিকানা পাবেন (এটাই গ্রাহকদের সাইট)।
3. আবার আলাদা সাইট হিসেবে **`2-admin-site` ফোল্ডারটি** আপলোড করুন → এটি অ্যাডমিন প্যানেল। **ঠিকানাটি গোপন রাখুন** (Site settings থেকে এমন নাম দিন যা অনুমান করা কঠিন)।
4. ইউজার ফোল্ডারে `index.html` ও `firebase-messaging-sw.js` **একই জায়গায়** থাকা চাই — নাম বদলাবেন না।

> অ্যাডমিন প্যানেল লগইন ছাড়া খোলে (আপনার চাওয়া অনুযায়ী) — তাই এর ঠিকানা কাউকে দেবেন না। তবে সার্ভার দিয়ে পুশ পাঠাতে `ADMIN_KEY` লাগে, তাই ঠিকানা জেনে গেলেও অচেনা কেউ ইউজারদের স্প্যাম পুশ পাঠাতে পারবে না।

## ধাপ ৬ — অ্যাডমিন প্যানেলে সব চালু করা

1. অ্যাডমিন সাইট খুলুন → **সেটিংস**।
2. **"পুশ নোটিফিকেশন সিস্টেম"** বক্সে:
   - সার্ভারের ঠিকানা: ধাপ ৩.২ এর Render ঠিকানা
   - অ্যাডমিন চাবি: ধাপ ৩.২ এর `ADMIN_KEY` হুবহু
   - VAPID Key: ধাপ ১.৪ থেকে
   - **"পুশ নোটিফিকেশন সিস্টেম চালু"** বাটন অন করুন
3. নিচে **সংরক্ষণ** চাপুন।
4. **"সার্ভার ও ডিভাইস পরীক্ষা"** চাপুন → সব ✅ দেখালে ঠিক আছে (প্রথমবার ১ মিনিট লাগতে পারে)।
5. "পাসওয়ার্ড ভুলে গেলে" বক্সে নিজের জিমেইল দিয়ে **টেস্ট মেইল** চাপুন → ইনবক্সে আসছে কিনা দেখুন।

### ফোনে ইউজারের দিক (পরীক্ষা)
1. ফোনের Chrome এ ইউজার সাইট খুলুন → অ্যাকাউন্ট/নোটিফিকেশন পেজে **"নোটিফিকেশন চালু করুন"** → Allow।
2. অ্যাডমিন থেকে নোটিফিকেশন পাঠান → ফোনে পুশ আসবে (অ্যাপ বন্ধ থাকলেও)।
3. **iPhone:** iOS 16.4+ লাগবে এবং আগে Safari → Share → **Add to Home Screen** করে হোম স্ক্রিন আইকন থেকে খুলতে হবে, তারপর নোটিফিকেশন চালু করা যাবে।

### Forgot Password (OTP) নিয়ম
- ৪ সংখ্যার কোড, **৫ মিনিট** মেয়াদ, ভুল হলে সর্বোচ্চ **৫ বার** সুযোগ, তারপর নতুন কোড লাগবে।
- পরপর কোড চাইতে **৪৫ সেকেন্ড** অপেক্ষা; একজন দিনে সর্বোচ্চ ১০টি।
- কোড যাচাই ও পাসওয়ার্ড বদল পুরোটাই সার্ভারে হয় (ডাটাবেসে কোড সরাসরি থাকে না, হ্যাশ থাকে এবং কোনো ইউজার সেটা পড়তে পারে না)।
- কোড জিমেইলে যায়; যে ইউজার আগে ঐ ডিভাইসে লগইন করেছিল তার ফোনে পুশেও যায় (পুশ চালু থাকলে)।
- ইমেইলে কোনো লিংক নেই, সাধারণ ও ছোট লেখা — স্প্যামে পড়ার ঝুঁকি কমাতে। তবু প্রথমবার কেউ স্প্যামে পেলে "Not spam" দিলে পরে ইনবক্সে আসবে। (কোনো সার্ভিসই ১০০% ইনবক্সের নিশ্চয়তা দিতে পারে না।)

## সীমা ও সতর্কতা (ফ্রি সিস্টেমে)
- জিমেইল (ফ্রি) দিনে প্রায় ৫০০টি মেইল পাঠাতে পারে — OTP এর জন্য যথেষ্ট।
- Firebase Spark (ফ্রি) প্ল্যানে Firestore এর দৈনিক পড়া/লেখার সীমা আছে; দোকান বড় হলে দেখে নেবেন। FCM পুশ সম্পূর্ণ ফ্রি।
- এই অ্যাপে Firebase Login নেই (নিজস্ব ইউজার সিস্টেম), তাই `users` ইত্যাদি কালেকশন ক্লায়েন্টের জন্য খোলা — এটি পুরনো কাঠামোর সীমাবদ্ধতা। OTP ও ডিভাইস টোকেন এই প্যাকেজে সম্পূর্ণ বন্ধ করা হয়েছে, কিন্তু ভবিষ্যতে বড় করলে Firebase Authentication-এ যাওয়া ভালো।
- `ADMIN_KEY`, Service Account `.json`, Gmail Client Secret ও Refresh Token — কাউকে দেবেন না। ফাঁস হলে Render এ নতুন করে বদলান।

### অ্যাডমিন প্যানেলে যা যা বদলেছে
- সেটিংসে নতুন **পুশ নোটিফিকেশন সিস্টেম** বক্স (মাস্টার বাটন, সার্ভার, চাবি, VAPID, পরীক্ষা বাটন) — পুরনো EmailJS অংশ বাদ।
- নোটিফিকেশন তৈরির ফর্মে **"পুশ নোটিফিকেশনও পাঠান"** বাটন; তালিকায় কতটি ডিভাইসে পুশ গেছে তার চিহ্ন।
- ইউজার সাইটে: ৪ সংখ্যার OTP, সার্ভারভিত্তিক পুশ ও ভুলে যাওয়া পাসওয়ার্ড, লগআউট করলে ডিভাইস ঐ ইউজার থেকে আলাদা হয়ে যায় (অন্যের নোটিফিকেশন আসে না)।
